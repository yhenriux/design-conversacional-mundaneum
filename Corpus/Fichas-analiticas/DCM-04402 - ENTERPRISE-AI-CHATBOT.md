## Resumo disponível

The evolution of enterprise applications has significantly benefited from advancements in artificial intelligence, particularly in enhancing user interaction and operational efficiency.This project introduces an AI-powered chatbot designed for enterprise environments, utilizing a combination of Retrieval-Augmented Generation (RAG) and Multi-Channel Processing (MCP) methodologies.Integrated with the Ollama platform within a C# ASP.NET Core environment, the chatbot is capable of retrieving context-relevant information from knowledge bases, enabling accurate and informative responses.MCP allows for a unified user experience across multiple communication platforms.The system incorporates local execution of large language models using the OllamaSharp library and Docker-based model hosting.This configuration supports fast response times, increased data privacy, and easier integration with existing enterprise systems.Overall, the solution aims to improve customer support, internal information retrieval, and task automation through secure and scalable AI technologies.
