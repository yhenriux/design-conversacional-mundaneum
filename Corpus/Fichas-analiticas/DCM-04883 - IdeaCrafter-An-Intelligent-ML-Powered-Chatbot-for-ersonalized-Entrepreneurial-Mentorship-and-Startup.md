## Resumo disponível

IdeaCrafter is an AI-driven chatbot web application that provides personalized guidance for entrepreneurs and investors based on a secure, role-based interface.The frontend ensures high performance and responsiveness with Next.js and React.js,while the UI design is enhanced by Tailwind CSS, shadcn/ui, and Lucide Icons.In turn, chat and user session state can be managed with Zustand or Redux.On the backend, Supabase is powered by a managed PostgreSQL database, Supabase Auth to handle email and magic link authentication, and RLS for data protection.Real-time chat updates support is enabled through the Supabase Realtime APIs and WebSockets for seamless communication.The chatbot will make use of the language model Llama 3.3-70B to make intelligent, contextually conscious responses, tailored to the user's role.Finally, Vercel hosts the application's frontend, with Supabase Cloud used for backend hosting, GitHub for version control, and continuous integration.Core features include AI-driven chat interaction, real-time synchronization, personalized dashboards, and role-based access.That offers scalability, security, and intelligence for investor-startup collaboration, including decision support.
