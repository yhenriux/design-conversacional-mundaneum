## Resumo disponível

This paper presents an API implementation for a BIM program written in .NET platform.The goal of this application is to launch the structure of a building automatically.The automation creates and controls the building's structural elements types using external text files with a dual purpose of being the source of information and to be the explicit description of the project.Our target is to create a definition of semantics that integrate the application with a voice user interface (VUI).The present version of the work is focused on a conventional and compact building type.
