## Resumo disponível

본 연구는 고령 사용자를 위한 모바일 금융 서비스의 사용자 경험(User Experience, UX)을 향상시키기 위한 인터페이스 설계 방안을 제시하고자, 세 가지 사용자 인터페이스(User Interface, UI) 유형의 효과를 비교·분석하였다. 구체적으로는 그래픽 사용자 인터페이스(Graphical User Interface, GUI), 음성 사용자 인터페이스(Voice User Interface, VUI), 대화형 디지털 휴먼(Conversational Digital Human, CDH)을 대상으로, UI 유형과 태스크(Task) 유형(계좌조회, 송금)이 고령 사용자의 UX(접근성, 신뢰도, 만족도)과 행동(수행시간, 오류율)에 미치는 영향을 실증적으로 검토하였다. 실험은 만 60세 이상 고령 사용자 33명을 대상으로 수행되었으며, 실제 금융 앱 흐름을 반영한 앱 기반 프로토타입을 활용하여 UI 유형별로 무작위 배정한 후 금융 태스크를 수행하도록 구성되었다. 데이터는 UX 설문, 수행시간 및 오류율 측정, 심층 인터뷰 등 혼합 방법을 통해 수집하였다. 통계 분석은 Kruskal-Wallis 검정 및 사후 Dunn’s Test(Bonferroni 보정)를 통해 수행되었으며, 정성 자료는 내용 분석(Content Analysis)을 통해 해석하였다. 분석 결과, GUI와 CDH는 접근성과 만족도 측면에서 가장 높은 평가를 받았고, CDH는 오류율에서 가장 낮은 수치를 기록하여 고령 사용자에게 안정적인 상호작용을 제공한 것으로 나타났다. 반면 VUI는 음성 인식 오류와 피드백의 비일관성으로 인해 접근성과 만족도 모두에서 낮은 평가를 보였다. 심층 인터뷰에서는 특히 CDH가 시각적·언어적 피드백을 반복 제공하며 고령 사용자의 정서적 안정에 기여한 것으로 분석되었다. 이러한 결과는 모바일 금융 서비스 설계에 있어 UI 유형과 태스크 맥락을 고려한 맞춤형 UX 전략의 필요성을 시사하며, 고령 사용자 친화적 UI 설계의 실증적 기초자료를 제공한다.
