## Resumo disponível

One of the most important problems of the voice user interface (VUI) design on portable maintenance aids (PMA) is the conflict between the complex speech recognition algorithms and the limited resource of PMA. To resolve this conflict, a VUI system based on cloud computing has been designed. This system adopts the speech recognition server on the background cloud computing platform to support the voice user interface in the foreground PMA. Compared with traditional VUI system, this system puts the complex speech recognition work to the background cloud computing platform, so that the computational burden of the foreground device has been reduced, which improves the recognition efficiency greatly, this improvement is particularly outstanding in the complex maintenance noise environment.
