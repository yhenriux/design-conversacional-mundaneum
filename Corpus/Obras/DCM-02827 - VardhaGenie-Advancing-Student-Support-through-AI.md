## Resumo disponível

This project describes the creation and deployment of an AI-powered chatbot intended to improve the user experience and accessibility of information for the Vardhaman College of Engineering (VCE) named VardhaGenie. The chatbot functions as a virtual assistant, answering questions and offering information on campus facilities, courses, and activities. To allow users and the chatbot to communicate seamlessly, the project uses modern Natural Language Processing (NLP) methods and neural network designs. The neural network model used in the chatbot design is built on deep learning concepts, which use sophisticated network layers to interpret and respond to user inquiries. In addition, several text preparation, tokenization, and feature extraction methods are used to improve the chatbot’s language comprehension skills.VardhaGenie uses the Bag of Words algorithm to efficiently handle a range of user questions, which contributes to the chatbot’s success in giving appropriate and context-aware replies about VCE facilities, services, and other relevant topics. The chatbot improves its ability to interpret user inputs and offer appropriate information after extensive training on a wide dataset of intents and replies related to the college environment. To achieve optimal performance, the model was iteratively refined and evaluated continuously during development. Overall, the chatbot project represents a big step forward in harnessing AI technology to deliver tailored help and expedite access to information about Vardhaman College of Engineering.
