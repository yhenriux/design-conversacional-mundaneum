## Resumo disponível

<jats:p>El propósito de esta investigación es crear una interfaz para facilitar la interacción del adulto mayor con personas que requieran un consejo, utilizando para ello la tecnología táctil, esto con la finalidad que este se desenvuelva con seguridad y eficiencia. El proyecto denominado Ni nanna, busca ser una alternativa tecnológica para los adultos mayores, facilitando con ello el uso de nuevas plataformas.</jats:p>
