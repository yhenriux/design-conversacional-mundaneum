## Resumo disponível

Abstract: Artificial Intelligence (AI) chatbots are becoming an essential component of modern communication systems, offering automated, intelligent, and context-aware interactions. This paper centers on the evolution of an AI chatbot using Pythonusing machine learning (ML) and natural language processing (NLP)techniques. The system processes user inputs through tokenization, lemmatization, and intent classification to deliver accurate responses. Implemented using Python libraries like NLTK and scikit-learn, the chatbot is designed in real timeinteraction and can be deployed using a web interface. The results demonstrate the chatbot’s ability to handle general conversations efficiently, showcasing its potential for use in customer support, education, and other service domains.
