## Resumo disponível

The proliferation of Large Language Models (LLMs) has catalyzed significant advancements in conversational AI, yet their application in high-stakes, structured domains like professional interviews remains a formidable challenge. The inherent non-determinism of probabilistic models conflicts with the requirement for predictable, multi-stage dialogue flows essential for fair and consistent candidate evaluation. This paper introduces a novel, hybrid system architecture that reconciles the flexibility of LLMs with the predictability of deterministic control. We present a real-time, voice-based conversational agent designed to conduct structured technical interviews. The system externalizes dialogue state management to a deterministic orchestration layer, which governs an LLM constrained to function as a state transition engine. By enforcing structured JSON outputs, leveraging prompt engineering as a state machine specification, and implementing runtime validation with state coercion, our approach ensures strict adherence to a predefined interview protocol. The architecture leverages WebSockets for low-latency, bidirectional audio streaming, achieving an end-to-end interaction latency of under two seconds. This work demonstrates a robust and generalizable architectural pattern for building reliable, task-oriented conversational agents that can be trusted in complex, real-world applications.
