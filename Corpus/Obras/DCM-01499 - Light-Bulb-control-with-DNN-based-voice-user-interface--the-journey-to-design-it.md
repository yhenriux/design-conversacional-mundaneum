## Resumo disponível

<jats:p>The purpose of a design journey is to show, in a demonstrative way, how to incorporate the DNN based voice user interface technology into a design. The base designs are by definition very simple to highlight the new technology and how it can be incorporated easily. Distinct lines are drawn between the application and the technology so the reader can more generalize how to incorporate it in their own design.</jats:p>
