## Resumo disponível

MedicAI is an AI-powered medical chatbot designed to provide accurate, context-aware healthcare information using Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs). Developed with Streamlit and deployed on AWS, it integrates ChromaDB and Neo4j for efficient data ingestion, indexing, and structured knowledge representation. The system leverages Langchain for chatbot orchestration and RAG implementation, while MLFLOW is utilized for evaluating responses and monitoring performance and also predicts the diseases like Cancer,Parkinson's etc using machine learning. The main aim of MedicAI is to enhance the user experience to provide greater patient engagement and better learning experience for students. Its architecture enables to be updated with latest trends and its retrieval strategy supports up-to-date with and by providing relevant information using complex retrieval strategies, By utilizing the Agentic approaches it can directly interact with data to provide the robust results. It uses the AI agents underhood to build the Doctor Appointment system. The paper demonstrates the usage of the Advanced Multi Agent architecture for doctor appointment system,The paper uses different algorithms like SVM, KNN, Randomforest, GradientBoosting, Logistic regression etc. whereas the gradient descent based optimizations one excels for the cancer prediction with an AUC of 0.86 and the KNN gives better overall performance in the Parkinson's disease prediction and the for the heart disease prediction the SVM algorithm performs better with recall score of 0.97.
