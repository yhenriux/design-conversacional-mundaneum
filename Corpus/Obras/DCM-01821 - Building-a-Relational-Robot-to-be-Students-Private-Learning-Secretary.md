## Resumo disponível

Relational robot is an intelligent conversational agent designed to be a learning secretary for student to notify student of using our learning Web site on time. In this paper we discuss some modules of relational robot to let it play a learning secretary role; it contains interaction module (verbal communication unit, nonverbal communication unit and process unit), internet interface, and communication interface with structure dialogue
