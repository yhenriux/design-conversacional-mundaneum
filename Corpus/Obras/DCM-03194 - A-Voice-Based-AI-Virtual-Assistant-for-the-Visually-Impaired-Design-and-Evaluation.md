## Resumo disponível

Visually impaired individuals face significant barriers when interacting with digital systems. This paper presents the design and implementation of a voice-based AI virtual assistant tailored to their needs. By leveraging natural language processing (NLP), text-to-speech (TTS), and voice user interfaces (VUI), the assistant enables tasks such as web search, time/date queries, music playback, and navigation support. The system is built using Python with integrated APIs (Google, Wikipedia, Wolfram Alpha, and weather services), aiming for high usability and accessibility. Preliminary testing demonstrates that the assistant provides real-time, context-aware responses and improves digital accessibility for the visually impaired.
