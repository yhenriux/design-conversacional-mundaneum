## Resumo disponível

Artificial Intelligence-based chatbots are transforming human-computer interaction by enabling intelligent, conversational, and automated assistance across multiple domains.This paper presents the design and implementation of an AI-powered intelligent desktop chatbot that integrates natural language processing, voice interaction, real-time web services, and a personalized recommender system within a single unified platform.The proposed system supports multiple real-world functionalities such as weather forecasting, Google Maps navigation, YouTube video search and playback, Wikipedia-based information retrieval, WhatsApp messaging automation, and online shopping assistance.The chatbot leverages a generative AI model for conversational intelligence and intent detection, along with a local machine learning-based intent classifier as a fallback mechanism to improve reliability.Voice interaction is enabled using speech recognition and text-to-speech synthesis, enhancing accessibility and user engagement.Additionally, a SQLite-based recommender system records user interaction history and provides smart, context-aware suggestions.The system demonstrates efficient response time, reliable automation, and improved user experience, making it suitable for real-time personal assistance and smart desktop applications.
