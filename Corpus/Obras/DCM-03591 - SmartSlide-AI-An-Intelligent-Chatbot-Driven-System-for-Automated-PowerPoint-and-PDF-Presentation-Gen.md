## Resumo disponível

Creating a well-structured slide presentation is a time-consuming task that combines research, content writing, visual design, and file-format handling.This paper presents SmartSlide AI, a conversational, chatbotdriven web platform that converts a natural-language request into a fully editable presentation, exported simultaneously as an OOXML PowerPoint (.pptx) file and a print-ready PDF.The system decomposes presentation authoring into a five-stage pipeline -requirement extraction, outline generation, slide-content generation, layout/theme rendering, and dual-format exportcoordinated by a REST API backend and an isolated Node.js presentation engine built on pptxgenjs.A provider-abstraction layer allows the AI engine to call OpenAI, Google Gemini, or Anthropic Claude interchangeably, while a deterministic "Demo AI Mode" guarantees the full pipeline remains demonstrable with no external API dependency and no fabricated citations.Five presentation themes and ten distinct slide layouts are implemented as native, schema-validated PowerPoint objects rather than rendered images, so every exported slide remains editable in Microsoft PowerPoint and LibreOffice Impress.The prototype was implemented end-to-end -authentication, project dashboard, chatbased requirement gathering, an in-browser slide editor, and export -and validated with an automated test suite (16 test cases, 100% pass rate) and empirical exportlatency measurements.Results show that a complete 10slide, thematically consistent, editable presentation can be produced and exported in under two seconds of computation (excluding network-bound LLM latency), demonstrating that a chatbot interface can meaningfully compress the presentation-authoring workflow while preserving full editability and design consistency.
