## Resumo disponível

The way we create chatbots is changing thanks to end-user development (EUD) tools. These tools allow developers without sophisticated programming abilities to build, implement, and deploy chatbots. As such, conversational artificial intelligence (AI) is more accessible across various industries, including customer service, e-commerce, and personal help. EUD tools allow for building and deploying chatbots with graphical, drag-and-drop interfaces incorporating NLPs. With pre-built template-based and visual programming environments and conversational AI, these tools allow for definitions of conversation flows, database integrations, API connectivity, and response personalization. By involving end-users in the design process, EUD tools help enable the design of chatbots to meet end-users’ needs, increasing functionality and improving user experiences. EUD tools even speed up testing and prototyping, making refining and enhancing chatbots easier and faster. Despite that, several challenges are still present. Simplicity in EUD tools can be accompanied by limitations in customizing and expressiveness of developed chatbots, while open privacy and security issues appear with some tools. Another important issue is the lack of support for polyadic chatbots since most EUD tools offer support for developing dyadic chatbots. This chapter provides an overview of chatbot design and development tools. It also covers future research trends and the advantages and disadvantages of these technologies.
