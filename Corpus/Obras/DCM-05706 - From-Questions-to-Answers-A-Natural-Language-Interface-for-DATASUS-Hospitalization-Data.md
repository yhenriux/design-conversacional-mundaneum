## Resumo disponível

To democratize access to Brazil’s DATASUS hospitalization data, we built a conversational agent that provides natural language responses to Portuguese questions. The agent uses a LangGraph and Llama 3.1:8B workflow to translate questions into SQL, achieving 100% end-to-end success and 82.9% execution accuracy on a 52-query benchmark. However, performance on complex queries dropped to 58.3%, revealing limitations in the LLM’s multi-step reasoning for multi-table analytical operations. Our work validates this stateful agentic approach and establishes a reproducible baseline for future extensions, including model benchmarking, domain-specific fine-tuning, and query decomposition strategies.
