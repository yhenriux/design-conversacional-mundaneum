## Resumo disponível

This paper explores design issues when creating a VoiceXML application, with special emphasis on grammar design and dialog flow. The paper can serve as a starting point for learning the basics of VoiceXML. The test application is an automatic directory assistance. Emneord: VoiceXML, vxml, Automatic Directory Assistance, Automated Speech Recognition, ASR, Text to Speech, TTS, dialog flow, Voice User Interface, VUI, VSP, Voice Service Provider
