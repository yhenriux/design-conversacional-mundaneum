## Resumo disponível

This project introduces a Web-based AI-Powered Campus Chatbot System for BITM to automate student queries and enhance campus interaction.It uses Flask, NLP, and a RAG-based FAISS search model to deliver accurate, context-aware responses from structured JSON datasets containing course details, fees, hostels, placements, and admissions information.The system includes secure admin/student authentication, an admin dashboard for updating placement images and chatbot data, and a student dashboard with an automatic 30second placement image slideshow.Interactive features such as speech-to-text, text-to-speech, and togglebased voice controls provide a smooth and accessible user experience.Overall, the project demonstrates how AI can simplify information access, reduce administrative effort, and modernize digital services within an educational institution.
