## Resumo disponível

The human machine interface (HMI) for interacting with computer numeric code (CNC) machines is predominantly constrained to touch-based user interfaces. These interfaces are limited in terms of operator mobility, -flexibility, -inclusivity, and -ease of interaction. Voice user interfaces (VUIs) have proven to be advantageous by mitigating the use of hands, the need for a navigation-based instruction manual, and the stationarity of the operator. Agentic artificial intelligence (Agentic AI) can be used for developing a flexible, adaptive, and inclusive VUI for speaking with CNC machines. However, implementation of such an approach bears challenges like the predictive accuracy of the large language models (LLMs), validation, and deployment of the software. Iterative training of LLMs, and validation of the solution is done by using a software in loop pipeline facilitated by the virtual twin of the CNC machine This article discusses in detail the conceptual framework, software architecture, and implementation details of a VUI for CNC-enabled 3-axis milling machine. It also discusses the challenges faced with training of the LLMs and validation of the software Additionally, this article discusses the shortcomings that need to be addressed to make such a solution deployable in an industrial scenario.
