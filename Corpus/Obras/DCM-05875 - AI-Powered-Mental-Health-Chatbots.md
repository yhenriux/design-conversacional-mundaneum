## Resumo disponível

This project presents the development of an AI-powered mental health chatbot aimed at providing instant emotional support and mental well-being guidance through intelligent conversation. The system is built using Natural Language Processing (NLP), Machine Learning, and sentiment analysis techniques, implemented through Python (with libraries like NLTK, TextBlob, and Hugging Face Transformers) and integrated via a Flask-based web interface.
