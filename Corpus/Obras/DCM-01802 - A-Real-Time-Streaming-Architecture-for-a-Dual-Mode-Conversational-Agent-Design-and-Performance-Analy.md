## Resumo disponível

The current market for AI-powered English-speaking practice tools is fragmented. Learners have to choose between open-ended conversational agents that lack phonetic feedback and structured assessment tools that lack conversational spontaneity. This paper presents the design and implementation of Aurora, a dual-mode conversational agent that bridges this pedagogical and technical gap. We detail a real-time streaming architecture built on a producer-consumer pattern. This system solves critical latency issues and enables a responsive user experience. It integrates an open-ended natural conversation partner with a structured IELTS test simulator into a single, cohesive application. Our key contributions include an “audio-aware” assessment approach that uses rich phonetic data from Microsoft Azure Speech Services to inform the qualitative analysis of a Large Language Model (Google Gemini), and a “Feedback Sandwich” model that delivers corrective tips without disrupting conversational flow. Preliminary evaluation demonstrates the system's technical feasibility, achieving a 3-7 second response latency and successfully validating both of its core functional modes. While this proof-of-concept demonstrates technical feasibility, limitations include transcription accuracy for non-native accents and the absence of user study validation, which represent critical areas for future work. This work provides a documented architectural blueprint for creating more integrated and effective AI-powered tools for oral proficiency development.
