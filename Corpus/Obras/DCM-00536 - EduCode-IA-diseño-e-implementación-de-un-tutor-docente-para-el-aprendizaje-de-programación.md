## Resumo disponível

Actualmente, los estudiantes en la Escuela Técnica Superior de Ingenieros Informáticos (ETSIINF) carecen de una tutorización personalizada continua en asignaturas introductorias como Programación I. En este proyecto se plantea EduCode-IA, la creación de una herramienta interactiva que recopila la teoría y normativas oficiales de la asignatura con el fin de generar asistencia pedagógica para aquellos alumnos que necesitan resolver dudas o corregir código, permitiendo un aprendizaje adaptado al temario sin automatizar la solución de forma directa. Para lograrlo, EduCode-IA se estructura en dos fases principales y cada una usa una tecnología diferente. En primer lugar, se realiza la ingesta del conocimiento con el objetivo de procesar los apuntes de la asignatura y el histórico de exámenes de forma eficaz. El formato elegido para realizar la tarea es el uso de una base de datos local basada en el procesamiento semántico, apoyada por la extracción de documentos PDF y el almacenamiento estructurado de ejercicios. De esta forma, se seleccionan los apuntes relevantes y se recopilan en un formato compatible con el de la siguiente etapa. En segundo lugar, se generan las respuestas pedagógicas y el entorno visual basados en los datos ya recuperados. El formato elegido para esta parte es un sistema conversacional coordinado en Python y centralizado en una interfaz web interactiva. De esta forma, se pueden importar los resultados de la etapa anterior, transformarlos como contexto, aplicar un mecanismo de validación para adaptarlo a los límites de la asignatura y delegar la generación del texto a un modelo de inteligencia artificial en la nube. Con todo ello se consigue una distribución de la información en un entorno integral con diferentes módulos, como el de teoría, corrección de código, generación de ejercicios y visualización de exámenes. El flujo de datos entre ambas etapas consiste en la recuperación de fragmentos de texto. La base de datos permite la exportación de información relevante y el orquestador permite la importación del mismo, su integración en la consulta y la transformación de la salida para el usuario. Durante el proyecto se detalla el diseño e implementación de ambas etapas, validando el funcionamiento de EduCode-IA a través de un riguroso proceso de pruebas y consultas que replican las dudas más frecuentes en el entorno académico. Este enfoque permite evaluar la utilidad pedagógica de la herramienta y fomentar que las respuestas ofrecidas por el tutor sean precisas, coherentes con el temario oficial y ajustadas al nivel de aprendizaje del estudiante. En conclusión, EduCode-IA constituye un prototipo funcional para explorar la integración de nuevas herramientas de apoyo pedagógico en la docencia universitaria, ofreciendo asistencia interactiva de forma dinámica, ininterrumpida y supervisada por una fuente fiable como es el temario oficial de la asignatura. ABSTRACT Currently, students at the Escuela Técnica Superior de Ingenieros Informáticos (ETSIINF) lack continuous personalized tutoring in introductory subjects such as Programming I. This project introduces EduCode-IA, an interactive tool that collects the official theory and guidelines of the course to provide pedagogical assistance to students who need to resolve doubts or debug code, enabling learning adapted to the syllabus without directly automating solutions. To achieve this, EduCode-IA is structured into two main phases, each utilizing different technologies. First, knowledge ingestion is performed, aiming to efficiently process course notes and exams history. The chosen format for this task involves a local database based on semantic processing, supported by PDF document extraction and structured exercise storage. In this way, relevant notes are selected and compiled into a format compatible with the subsequent stage. Second, pedagogical responses and the visual environment are generated based on the retrieved data. This part is managed by a conversational system coordinated in Python and centralized in an interactive web interface. This allows results from the previous stage to be imported, transformed into context, validated against course constraints, and used to delegate text generation to a cloud-based artificial intelligence model. This results in the distribution of information within an integrated environment featuring different modules for theory, code correction, exercise generation, and exam visualization. The data flow between both stages consists of retrieving text fragments. The database allows for the export of relevant information, while the orchestrator enables its import, integration into queries, and output transformation for the user. Throughout the project, the design and implementation of both stages are detailed, validating the tutor's performance through a rigorous testing process that replicates frequent academic inquiries. This approach makes it possible to assess the pedagogical effectiveness of the tool and to enhance the accuracy and consistency of the responses provided by the tutor with respect to the official syllabus and the student's learning level. In conclusion, EduCode-IA represents a functional prototype to explore the integration of new pedagogical support tools in university teaching, offering interactive assistance in a dynamic, uninterrupted manner, supervised by a reliable source, the official course syllabus.
